# Learn the finite receiver story

The question is concrete: a source leaves one qutrit direction empty, and the receiver must identify that wholly unknown ray. The experiment compares complete output risks at finite specimen budgets, then asks whether storage imperfections and paid calibration preserve the gain.

Use the selected **Demkowicz-Dobrzański–Górecki–Guţă 2020 review**, [arXiv:2001.11742v2](https://arxiv.org/abs/2001.11742v2), as the single educational anchor. The [anchor bridge](ANCHOR.md) gives a focused section path, translates notation and cost normalization, and identifies the mathematical steps supplied by this project. The scientific research references retain their separate attribution role.

Start with [Finding the direction the source never occupies](STORY.md). It follows one orientation through all pair branches, two actual posterior decisions, the three-specimen guarantee and the larger paid-calibration ledger. Then use the [30-milestone map](MILESTONES.md) to connect the complete story to the proofs.

## Keep three distinctions visible

**A mixed specimen is not its pure target.** The source provides $`(I-P_f)/2`$, while the target is $`P_f`$. A pure conditional wedge occurs only in one charged branch of a two-specimen experiment.

**A local information comparison is not a finite global guarantee.** The exact three-specimen certificate and the finite noisy-risk inequalities supply the required output-loss comparison. Numerical comparisons with selected one-copy estimators have a narrower evidential role.

**A calibrated scalar is not a calibrated receiver.** The reference test learns a storage parameter within a specified independent stationary depolarizing model. Known reference preparation and the separate control/readout tolerance remain explicit promises. The [worked story](STORY.md) keeps that boundary in the final ledger.
