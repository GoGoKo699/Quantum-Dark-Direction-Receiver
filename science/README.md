2. [Receiver](receiver.md): parity, the conjugate hole, and the finite 24- and 450-outcome constructions.

4. [Finite implementation](implementation.md): randomized settings, bounded precision and physical dilation resources.
5. [All one-copy protocols](one-copy-bound.md): a global finite lower bound for arbitrary adaptive histories.
6. [Imperfect storage](memory-noise.md): a global matrix estimator and its unconditional finite risk.
7. [Paid calibration](calibration.md): independent references, rejection, false certification and a strict total-budget comparison.
